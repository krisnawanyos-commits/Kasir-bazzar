Integrasi Google Sheets & Google Drive

Cara Kerja Tracing Real-Time:

Setiap kali kasir menekan tombol Selesaikan Transaksi, rincian belanjaan dan total bayar akan otomatis terkirim ke Google Sheet di Drive kamu.

Cara Menghubungkan Google Sheet Kamu (Cuma 1 Menit):

  1. Buka Google Drive & buat Google Sheets baru. Beri judul misal: Rekap Sales Bazaar.
  2. Di Google Sheets, klik menu Ekstensi (Extensions) → Apps Script.
  3. Hapus semua kode lama di Apps Script, lalu Copy-Paste Kode Berikut:
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["No Transaksi", "Tanggal & Waktu", "SKU Code", "Nama Barang", "Brand", "Subsidiary", "Harga Jual", "Qty", "Discount", "Amount", "Status"]);
  }
  data.items.forEach(function(item) {
    var amt = item.isGimmick ? 0 : Math.max(0, (item.price * item.qty) - item.discount);
    var status = item.isGimmick ? "GIMMICK / FREE" : "PAID";
    sheet.appendRow([
      data.id,
      data.formattedTime,
      item.sku || "-",
      item.name || "-",
      item.brand || "-",
      item.subsidiary || "-",
      item.price,
      item.qty,
      item.discount,
      amt,
      status
    ]);
  });
  return ContentService.createTextOutput("OK");
}
  1. Di Apps Script, klik Terapkan (Deploy) → Penerapan Baru (New Deployment).
  2. Pilih Jenis: Aplikasi Web (Web App).
  3. Atur Siapa yang memiliki akses (Who has access): pilih Siapa Saja (Anyone).
  4. Klik Terapkan (Deploy), lalu Salin URL Aplikasi Web dan tempelkan pada kolom di atas!
